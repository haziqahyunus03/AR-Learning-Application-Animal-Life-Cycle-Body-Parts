
# 🐾 AR Learning Application
### Animal Life Cycle & Body Parts

An **Augmented Reality (AR) educational application** designed to make early childhood learning more interactive through animal-themed learning materials, scan-enabled videos, and an accompanying educational flipbook.

[📱 Download Android APK](https://drive.google.com/file/d/10ZKWNgEmttqUlCc1PlKktJ9AhfciZiM1/view?usp=sharing) · [📖 View Animal Flipbook](https://drive.google.com/file/d/1KEG4MyOwj0m9K9x7IVAaDlvlRQz1ccnN/view?usp=sharing)

---

## ✨ Project Highlights

- 🦋 **Animal Life Cycles** — Explore the life cycles of different animals through AR-enabled educational content.
- 🐸 **Interactive Learning** — Educational activities designed to encourage children's participation.
- 📱 **Augmented Reality** — Scan images to access related AR video content.
- 📚 **Companion Flipbook** — An educational book supporting the learning experience.

## 🎯 Project Objectives

- Make early childhood learning more engaging through interactive technology.
- Introduce animal life cycles and body parts using visual learning materials.
- Combine an Android application with a companion educational book.

## 👩‍💻 My Contributions

- Collaborated with a three-member team to develop an AR learning application and companion book for a TASKA client in Melaka.
- Developed the Android application using Unity and integrated AR features.
- Created scan-enabled AR video content featuring animal life cycles.
- Contributed to interactive educational activities and learning materials.

## 🛠️ Technologies & Tools

- **Unity** — Application development
- **Augmented Reality (AR)** — Interactive learning experience
- **Canva** — Educational book design
- **CapCut** — AR video editing
