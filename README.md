# AR Learning Application: Animal Life Cycle & Body Parts

## Project Overview
An augmented reality (AR)-based educational application developed to support children's learning through interactive animal-related content and a companion flipbook.

## Key Features
- AR-enabled educational content accessed by scanning images.
- Interactive learning materials about animal life cycles and body parts.
- Companion animal flipbook in PDF format.

## My Contribution
- Collaborated with a three-member team to develop an AR learning application and companion book for a TASKA client in Melaka.
- Created scan-enabled AR video content for educational learning.
